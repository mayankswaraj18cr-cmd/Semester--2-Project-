# Mounting Plate CAD

A browser-based 2D mechanical drawing and reference guide for a mounting plate.

## Overview

This project presents the dimensions, drafting conventions, and construction
steps for a mechanical mounting plate in a compact interactive HTML page. It
combines a visual drawing with specifications, CAD commands, and supporting
research material for review or classroom presentation.

## Features

- Interactive 2D mounting-plate drawing with selectable views and dimensions
- Quick-reference table for the component specifications and CAD workflow
- Supporting research paper and presentation materials

## Getting Started

Clone the repository and open `mounting_plate_cad.html` in a browser. No build
tool or dependency installation is required.

```bash
git clone https://github.com/mayankswaraj18cr-cmd/Semester--2-Project-.git
cd Semester--2-Project-
```

For a local web server, run:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000/mounting_plate_cad.html`.
